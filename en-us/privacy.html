Policy

Privacy Policy

Last updated: August 18, 2026

For the conditions that apply to your use of Mark'n Memo, see the separate Terms of Use.

1. Introduction

Masatiki provides Mark'n Memo, a note-taking app that lets users create and manage text notes using typed input, voice input, categories, and reminder notifications.

This policy explains the information Mark'n Memo handles, the information stored on your device, the information that may be processed through Firebase Remote Config and Firebase Analytics (Google Analytics for Firebase), and the current inclusion of the Google Mobile Ads SDK and Google User Messaging Platform (UMP) SDK as library dependencies.

2. Information stored on your device

Mark'n Memo stores the following information on your device to provide the app’s features:

  • Memo text you create
  • Category names you create
  • Memo and category order
  • The status of deleted memos used within the app
  • Alarm and reminder settings you create
  • App settings such as language, theme, UI mode, background color, memo date/time display, app lock, and privacy choices

This information is used to operate the memo, category, settings, notification, and alarm features. In the current version, Mark'n Memo does not send memo text, category names, or alarm content to a server managed by Masatiki.

3. Voice input

Mark'n Memo uses the microphone only when you start voice input. Voice input uses the speech recognition service available on your Android device to convert speech into text.

Mark'n Memo does not save your voice as an audio recording. Supported languages, recognition accuracy, and processing methods may vary by device, Android version, installed speech recognition service, language setting, and network conditions.

4. Backup, restore, export, and import

Mark'n Memo uses Android’s system file picker to save backup/export files and open restore/import files. You choose the on-device location or document provider, such as Google Drive.

Mark'n Memo does not implement its own Google sign-in, use the Drive API, or retain Drive credentials. A file can contain memo text, categories, order, settings, alarms, and deletion state, but the transfer and destination or source are selected by you.

5. Notifications and alarms

Mark'n Memo uses on-device notifications and alarms for reminders you create. Depending on your device and lock-screen settings, a notification may display memo text.

These notifications and alarms are used only for reminders you create. They are not used for advertising or marketing notifications.

6. Firebase Analytics

Mark'n Memo uses Firebase Analytics (Google Analytics for Firebase) to understand app usage and improve product quality.

The current version primarily records events such as:

  • Screen views and session starts
  • Creation of typed memos
  • Starting voice input and saving a memo from voice input
  • Creating a category
  • Setting an alarm
  • Changing language, theme, UI mode, background color, or similar settings

These analytics events do not include memo text, category names, recorded audio, alarm times, or notification text. Firebase Analytics may collect app interaction and session information, approximate location derived from information such as IP address, device information, app instance IDs, Android advertising IDs, and other device- or app-related identifiers.

7. Home announcements and Firebase Remote Config

Mark'n Memo uses Firebase Remote Config to download a short home-screen announcement without requiring an app update. The app performs a limited asynchronous refresh after the home screen and voice input are ready. If the refresh fails, the app uses a local default or a previously cached value.

Remote Config may automatically process country code, language code, time zone, platform and OS version, Firebase app ID, package name, SDK version, and a Firebase installation ID. It does not receive memo text, category names, raw or recognized voice content, alarm times, or notification text. Mark'n Memo does not request GPS or precise location for announcements.

8. Advertising and privacy choices

Mark'n Memo includes the Google Mobile Ads SDK and Google User Messaging Platform (UMP) SDK as library dependencies. Advertising is disabled in the current public version, so UMP does not update consent information, show consent forms, or run privacy-choice processing. The app also does not initialize the Google Mobile Ads SDK, request ads, or display ads.

The current version makes no ad requests. If advertising is enabled in the future, Mark'n Memo will not include memo text, category names, raw or recognized voice content, or alarm content in ad requests. Before enabling advertising, Masatiki will review this Privacy Policy and the Google Play Data safety disclosure.

9. Information Mark'n Memo does not request

Mark'n Memo currently does not provide user accounts and does not include app fields that ask users to enter the following:

  • Name
  • Email address
  • Phone number
  • Street address
  • Payment information
  • Contacts
  • Photos or videos
  • Calendar events
  • Precise location

Mark'n Memo does not use the content of your notes for advertising targeting.

10. Third-party services

Mark'n Memo uses Firebase Remote Config and Firebase Analytics (Google Analytics for Firebase), provided by Google, for announcements, analytics, and quality improvement. The Google Mobile Ads SDK and Google User Messaging Platform (UMP) SDK are also included as library dependencies, but their advertising and consent processing does not run because advertising is disabled in the current public version.

For information about Google’s privacy practices, see the Google Privacy Policy.

11. Sharing of data

Masatiki does not sell user data. Remote Config and Analytics information is processed through Google services for the purposes described above.

In the current version, Mark'n Memo does not send memo text, category names, recorded audio, recognized text, or alarm content to a server managed by Masatiki. The current version makes no ad requests, and Mark'n Memo will not add this content to ad requests if advertising is enabled in the future.

12. Data deletion and contact

You can delete memos and categories within the app. Mark'n Memo currently does not provide user accounts or a Masatiki-managed user database, so most memo data is stored on your device.

For privacy questions or requests related to analytics data processed through Firebase Analytics, contact marknmemo+contact@gmail.com.

13. Changes to this policy

Masatiki may update this policy when app features or data practices change. Before adding or materially changing features such as cloud sync, accounts, production advertising, subscriptions, AI transcription, or crash reporting, Masatiki will review this policy and the Google Play Data safety disclosure.
