# Security Policy / セキュリティポリシー

## 脆弱性の報告

Mark'n Memo または公式サイトにセキュリティ上の問題を発見した場合は、
公開 Issue へ詳細を書かず、`marknmemo+contact@gmail.com` へメールでご連絡
ください。件名の先頭に `[Security]` を付けてください。

可能であれば、影響を受けるアプリのバージョンまたはURL、再現手順、想定される
影響、端末・Androidバージョンを記載してください。メモ本文、認証情報、APIキー、
署名鍵、個人情報は送らないでください。追加資料に機密情報が必要な場合は、送付前に
安全な共有方法を相談してください。

修正と利用者保護のため、公開前に合理的な確認・対応期間を設けていただくようお願い
します。

## Reporting a vulnerability

If you discover a security issue in Mark'n Memo or its official website, do not
post the details in a public issue. Email `marknmemo+contact@gmail.com` with
`[Security]` at the beginning of the subject line.

When possible, include the affected app version or URL, reproduction steps,
expected impact, device model, and Android version. Do not send memo content,
credentials, API keys, signing keys, or personal data. If sensitive supporting
material is necessary, contact us first to agree on a safer transfer method.

Please allow a reasonable period for validation, remediation, and user
protection before public disclosure.
